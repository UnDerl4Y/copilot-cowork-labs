# Repository Conventions

## Naming

- Use lowercase directory names.
- Use hyphens between words.
- Use descriptive file names.
- Preserve the lab numbering.

## Documentation

- Include objectives and prerequisites.
- Identify files to create or modify.
- Include expected results.
- Provide verification instructions.

## Source control

- Do not commit secrets.
- Keep dependency lockfiles.
- Exclude local runtime artifacts.
- Keep assessment answers outside participant materials.

## Architecture

- Separate transport from business logic.
- Validate tool inputs.
- Use structured responses.
- Document errors and permissions.
