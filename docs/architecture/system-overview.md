# System Overview

## Architecture objective

Provide a shared technical foundation for three guided labs
and five independent business implementations.

## Main components

1. Custom Cowork skills.
2. MCP servers hosted on Azure Functions.
3. Cowork plugin packages.
4. Copilot Studio agents.
5. Enterprise identity and governance services.

## Implementation journey

Lab 01 creates the skill.

Lab 02 adds the MCP connector and plugin packaging.

Lab 03 reuses the MCP server in Copilot Studio.

Group Build combines the components against an unseen dataset.

## Architecture principle

Business logic remains use-case-specific.
Shared infrastructure remains reusable.
