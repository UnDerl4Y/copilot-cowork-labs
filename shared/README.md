# Shared Components

Reusable components used by the guided labs and business solutions.

## Directories

- `schemas/` - Shared JSON schemas.
- `types/` - Common TypeScript types.
- `utilities/` - Reusable implementation utilities.
- `test-utilities/` - Shared testing helpers.
- `configuration-templates/` - Safe configuration examples.

Keep business-specific logic inside the corresponding use case.
