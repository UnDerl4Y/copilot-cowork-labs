# Copilot Cowork Developer Labs

A hands-on developer repository for building custom skills,
MCP connectors, plugins and Copilot Studio integrations.

## Learning journey

| Stage | Activity |
|---|---|
| Lab 01 | Build custom skills |
| Lab 02 | Build MCP connectors and package plugins |
| Lab 03 | Integrate the same MCP server with Copilot Studio |
| Group Build | Complete an end-to-end business use case |
| Presentation | Demonstrate the completed solution |

## Repository structure

- `getting-started/` - Environment preparation.
- `labs/` - Three progressive guided labs.
- `group-build/` - Final end-to-end business challenge.
- `shared/` - Reusable schemas and utilities.
- `docs/` - Public technical documentation.
- `scripts/` - Development and validation automation.
- `tests/` - Repository-level validation.
