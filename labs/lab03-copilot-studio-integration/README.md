# Lab 03 - Copilot Studio Integration

## Objective

Connect the same MCP server to a Copilot Studio agent.

**Estimated duration:** 30 minutes

## Topics

- MCP server integration
- Agent configuration
- Tool invocation
- Response comparison

## Exercise sequence

1. Identify the MCP server created in Lab 02.
2. Configure the MCP connection in Copilot Studio.
3. Add the connector to the agent.
4. Test representative business questions.
5. Compare Cowork and Copilot Studio behaviour.

## Expected deliverable

A Copilot Studio agent using the same MCP server.

## Completion criteria

Both Cowork and the Copilot Studio agent can access the intended tools.
