# Lab 01 - Custom Skills

## Objective

Create a business-specific custom skill using SKILL.md and reference files.

**Estimated duration:** 60 minutes

## Topics

- Skill structure and SKILL.md
- Instructions and reference files
- Writing clear and testable instructions
- Business rules and constraints
- Skill execution and validation

## Exercise sequence

1. Inspect the starter skill.
2. Identify the business objective and constraints.
3. Create the required reference files.
4. Write the skill instructions.
5. Test the skill against representative scenarios.
6. Preserve the completed skill for Lab 02.

## Expected deliverable

A tested custom skill with its reference files.

## Completion criteria

The skill follows its defined business rules and produces the required output structure.
