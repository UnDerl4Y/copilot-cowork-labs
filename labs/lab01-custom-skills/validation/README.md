# Validation

## Objective

Verify the deliverable for Lab 01 - Custom Skills.

## Validation checklist

- [ ] Required files exist.
- [ ] Configuration is valid.
- [ ] Expected behaviour is demonstrated.
- [ ] Invalid input is handled.
- [ ] No secrets are committed.
- [ ] Deliverable is ready for the next stage.

## Expected result

The skill follows its defined business rules and produces the required output structure.
