# Lab 02 - MCP Connectors and Plugins

## Objective

Implement MCP tools, secure the connector and package the custom skill and connector as a plugin.

**Estimated duration:** 90 minutes

## Topics

- MCP server architecture
- Tool naming and structured JSON schemas
- Azure Functions and Streamable HTTP
- Entra OAuth
- Approval-gated write operations
- Plugin manifests and packaging

## Exercise sequence

1. Inspect the MCP starter project.
2. Understand the required tool contracts.
3. Implement the business-specific MCP tools.
4. Add input validation and explicit error responses.
5. Configure authentication and permissions.
6. Package the skill and connector together.
7. Test the packaged plugin.

## Expected deliverable

A working MCP connector and packaged Cowork plugin.

## Completion criteria

Required tools return structured responses and the plugin can be tested in the target environment.
