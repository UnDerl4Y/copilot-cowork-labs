# Deal Desk: Agent-Operated Renewal Pack

## Business owner

Chief Revenue Officer

## Business problem

Renewal preparation involves fragmented CRM, contract and pricing information.

## Expected skill

Apply pricing rules, discount bands and proposal requirements.

## Required MCP tools

get_account, get_contracts, price_quote, request_discount

## Expected business output

Word renewal proposal, Excel pricing sheet and Teams summary.

## Build sequence

1. Review the business requirements.
2. Implement the skill.
3. Implement and validate the MCP tools.
4. Package the plugin.
5. Integrate the same MCP server with Copilot Studio.
6. Process the unseen dataset.
7. Validate the final output.
