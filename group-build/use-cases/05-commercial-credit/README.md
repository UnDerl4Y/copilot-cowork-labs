# Commercial Loan Credit Memo

## Business owner

Chief Risk Officer

## Business problem

Credit memo preparation requires verified financial information, exposure data and policy checks.

## Expected skill

Apply credit policy, ratio definitions and memo requirements.

## Required MCP tools

get_borrower, get_financials, get_exposure, check_policy_limits

## Expected business output

Confidential Word credit memo with verified ratios and policy exceptions.

## Build sequence

1. Review the business requirements.
2. Implement the skill.
3. Implement and validate the MCP tools.
4. Package the plugin.
5. Integrate the same MCP server with Copilot Studio.
6. Process the unseen dataset.
7. Validate the final output.
