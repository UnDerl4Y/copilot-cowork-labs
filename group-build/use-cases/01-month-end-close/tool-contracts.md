# MCP Tool Contracts

## Required tools

get_ledger, get_budget, flag_variance

For every tool, document:

- Tool name and description.
- Input JSON schema.
- Required and optional fields.
- Output JSON schema.
- Pagination behaviour.
- Validation rules.
- Error responses.
- Authentication and authorization.
- Read or write classification.

Do not invent production schemas. Define contracts against the supplied dataset.
