# Acceptance Criteria

## Skill

- [ ] Business rules are implemented.
- [ ] Reference files are used correctly.
- [ ] Unsupported information is not invented.

## Connector

- [ ] All required MCP tools are implemented.
- [ ] Input and output schemas are validated.
- [ ] Errors are explicit.
- [ ] Permissions are appropriate.

## Plugin

- [ ] Skill and connector are packaged.
- [ ] Manifest follows the supported schema.
- [ ] Package executes successfully.

## Copilot Studio

- [ ] Same MCP server is reused.
- [ ] Required tools are accessible.
- [ ] Representative questions are tested.

## Business output

- [ ] Unseen dataset is processed.
- [ ] Calculations are accurate.
- [ ] Exceptions are surfaced.
- [ ] Output follows business requirements.

## Evidence

Record actual results and supporting test evidence.
