# Month-End Close: Variance Commentary Pack

## Business owner

Chief Financial Officer

## Business problem

Analysts spend significant time preparing ledger variance commentary and controllers must review inconsistent explanations.

## Expected skill

Apply materiality thresholds, account mappings and commentary style rules.

## Required MCP tools

get_ledger, get_budget, flag_variance

## Expected business output

Excel variance pack containing flagged lines, source figures and explanations.

## Build sequence

1. Review the business requirements.
2. Implement the skill.
3. Implement and validate the MCP tools.
4. Package the plugin.
5. Integrate the same MCP server with Copilot Studio.
6. Process the unseen dataset.
7. Validate the final output.
