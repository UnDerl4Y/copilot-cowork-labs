# Supplier Risk Review at Scale

## Business owner

Chief Procurement Officer

## Business problem

Supplier reviews require evidence gathered across spend, certification and audit systems.

## Expected skill

Apply the risk scoring rubric, weights and evidence requirements.

## Required MCP tools

get_supplier, get_spend, get_certifications, get_audit_findings

## Expected business output

Word supplier risk memo and Excel scorecard with cited evidence.

## Build sequence

1. Review the business requirements.
2. Implement the skill.
3. Implement and validate the MCP tools.
4. Package the plugin.
5. Integrate the same MCP server with Copilot Studio.
6. Process the unseen dataset.
7. Validate the final output.
