# Group Solution Workspace

Use this structure as the workspace for the assigned business solution.

Extend the artifacts produced in Labs 01–03.

## Components

- `skill/` - Custom skill and references.
- `connector/` - MCP connector implementation.
- `plugin/` - Plugin manifest and package assets.
- `copilot-studio/` - Agent integration.
- `tests/` - Business and integration tests.
- `outputs/` - Generated business deliverables.

Do not copy private trainer materials into this workspace.
