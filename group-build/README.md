# Group Build

## Objective

Complete an end-to-end business solution using the skill,
MCP connector and plugin developed in Labs 01–03.

## Execution model

Each group receives one assigned business use case.

The completed implementation must work against an unseen dataset.

## Group workflow

1. Review the assigned business requirements.
2. Reuse the custom skill developed in Lab 01.
3. Extend the connector developed in Lab 02.
4. Reuse the plugin package.
5. Integrate the same MCP server with Copilot Studio.
6. Execute the solution against the unseen dataset.
7. Verify the output against the acceptance criteria.
8. Prepare the final demonstration.

## Groups

| Group | Business use case |
|---|---|
| 1 | Month-End Close |
| 2 | Supplier Risk Review |
| 3 | Deal Desk |
| 4 | Incident Post-Mortem |
| 5 | Commercial Loan Credit Memo |

## Duration

60 minutes of trainer-supported group building.

## Final deliverable

A working business solution with implementation, test evidence
and a demonstration.
