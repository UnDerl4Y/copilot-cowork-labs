# Group Build Acceptance Criteria

## Skill

- Business rules are followed.
- Required references are used.
- Missing information is not invented.
- Output follows the specified structure.

## MCP connector

- Required tools are available.
- Input schemas are validated.
- Responses use structured data.
- Errors are explicit.
- Permissions follow least privilege.

## Plugin

- Required skill and connector assets are included.
- Manifest matches the supported package specification.
- Package is successfully tested.

## Copilot Studio

- The same MCP server is reused.
- Required tools can be invoked.
- Responses are compared with Cowork.

## Business output

- Output matches the use-case requirements.
- Source data can be traced.
- Exceptions and missing data are surfaced.
- Approval requirements are respected.

## Evidence

Every criterion must have a demonstrable verification result.
