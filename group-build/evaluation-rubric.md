# Group Build Evaluation Rubric

Evaluate the following dimensions:

| Dimension | Evaluation focus |
|---|---|
| Business understanding | Correct interpretation of requirements |
| Custom skill | Instruction quality and rule adherence |
| MCP connector | Tool design and response correctness |
| Plugin | Packaging and successful execution |
| Copilot Studio | Reuse of the same MCP server |
| Data accuracy | Correct processing of unseen data |
| Governance | Permissions, approvals and data protection |
| Demonstration | Clear architecture and live execution |

Define scoring weights and pass thresholds before delivery.
