# Unseen Data Protocol

## Purpose

Evaluate whether the completed solution generalizes beyond
the sample data used during guided labs.

## Preparation

- Prepare a separate assessment dataset.
- Validate the dataset schema.
- Confirm the dataset matches the use-case data contract.
- Keep reference outputs access-controlled.
- Do not expose assessment answers in participant materials.

## Execution

1. Supply the unseen dataset at the start of Group Build.
2. Run the completed solution.
3. Record tool inputs and outputs.
4. Validate business calculations.
5. Check missing data and exceptions.
6. Compare the generated deliverables with expected outcomes.

## Security

Do not commit private assessment datasets or answer keys
to the participant repository.
