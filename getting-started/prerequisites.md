# Prerequisites

## Development knowledge

- JavaScript or TypeScript fundamentals.
- REST API concepts.
- JSON and HTTP.
- Basic Git operations.
- Familiarity with Copilot Studio.

## Required tools

| Tool | Purpose |
|---|---|
| Visual Studio Code | Development environment |
| Node.js LTS | MCP and application development |
| npm | Dependency management |
| Git | Source control |
| PowerShell 7 | Environment automation |
| Azure access | Cloud resources and Functions |
| Microsoft 365 Copilot Cowork | Skill and plugin execution |
| Copilot Studio | Agent integration |

Confirm the required CLI versions and tenant permissions before starting.
