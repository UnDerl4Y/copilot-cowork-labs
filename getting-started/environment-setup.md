# Environment Setup

## Objective

Prepare a working environment for the three guided labs.

## Setup checklist

- [ ] Confirm development machine requirements.
- [ ] Install Visual Studio Code.
- [ ] Install Node.js LTS.
- [ ] Install Git.
- [ ] Install required PowerShell version.
- [ ] Verify Azure access.
- [ ] Verify Microsoft 365 and Cowork access.
- [ ] Verify Copilot Studio access.
- [ ] Verify network connectivity.

## Verification

Record installed versions and confirm that all required services
are accessible.

Do not store credentials or access tokens in source control.
